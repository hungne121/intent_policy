Intention information type:
    1. Spatial information
    2. Time information
    3. Semantic information

In HRI, robot need to know answer of these 5 questions:
    1. What: what action had to be done?
    2. Who: Who will do it?
    3. Which: Which objects for the action?
    4. Where: Where to do it?
    5. When: What time it should start the action and end it?

We need the intention information to help answer these questions.
    1. What: Semantic (language, task id...)
    2. Who: Semantic (language, task id...)
    3. Which: Spatial (gaze, hand gesture...) & Semantic (language...)
    4. Where: Spatial (gaze, hand gesture...) & Semantic (language...)
    5. When: Time (this is where the predict matter, the spatial and semantic information being predict give robot the time to response/act.)

So now whe need a source of information or socall information cue which will give us enough information. And what type of data the information will be, becouse if we assume the kind of data of the intention information. Model will be shock when it come to real data come from real predictor.
